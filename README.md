# Amazon Sales & Business Performance Dashboard

A professional Streamlit management dashboard built from Amazon Sales Data India.

## Features
- Executive KPIs: sales, profit, orders, units, AOV, profit margin
- Monthly sales and profit trends
- Category-wise sales, profit and units
- Top 10 products
- Order status, return rate and cancellation rate
- Category-wise returns and cancellations
- Payment-method sales and profit
- Fulfillment-method sales and profit
- State-wise sales, profit and orders
- Automated management insights
- Interactive filters
- Filtered CSV download

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

The Excel file must remain at:

`data/Amazon Sales Data India.xlsx`
